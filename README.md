# 🍫 DaddyChocolat

Application de point de vente et de gestion e-commerce pour chocolats artisanaux de Madagascar (Vallée du Sambirano).

Projet réalisé dans le cadre de l'examen de **Licence 2 Informatique / Génie Logiciel**.

---

## 🚀 Technologies utilisées

- **Frontend :** React (Vite), Tailwind CSS
- **Backend :** Node.js, Express.js
- **Base de données :** MySQL (XAMPP / phpMyAdmin)

---

## 📋 Prérequis

- Node.js installé
- XAMPP (avec Apache et MySQL démarrés)

---

## 🛠️ Installation et Lancement

### 1. Base de données
1. Ouvrez **phpMyAdmin** (`http://localhost/phpmyadmin`).
2. Importez ou exécutez le script SQL situé dans `backend/database.sql`.

### 2. Démarrer le Backend
```bash
cd backend
npm install
node server.js
